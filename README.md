# 2026-2027 Planner

A hyperlinked digital planner (daily, weekly, monthly, yearly + 60+ templates) in rose pink and teal.
Works on desktop and iPhone as an installable web app, hosted free on GitHub Pages.

## Put it on GitHub Pages
1. Create a new GitHub repository (e.g. `my-planner`), public or private (private Pages needs a paid plan).
2. Upload every file in this folder to the repository root (Add file → Upload files).
3. Repo → Settings → Pages → Source: "Deploy from a branch" → Branch `main`, folder `/ (root)` → Save.
4. After a minute your planner is live at `https://YOUR-USERNAME.github.io/my-planner/`.

## Install it like an app
- iPhone: open the link in Safari → Share → Add to Home Screen.
- Mac: Safari → File → Add to Dock (or Chrome/Edge → Install).
- Windows: Edge/Chrome → Install icon in the address bar.

## Good to know
- Everything you type is saved on the device you use. To move to another device, use Settings → Export backup, then Import backup there.
- The Password Tracker is not encrypted. Store hints only.
- Edit `CATS` in `app.js` to rename or add template pages.
